## Project Structure
-   All `.csv` files are located in the `data` folder, either as a `processed` CSV or `raw` CSV.
-   All `.ipynb` files are located in the `notebooks` folder.
-   All `.png` files are located in the `reports` folder.
-   All `.py` files are located in the `src` folder.
-   To run `.ipynb` files, click `Run All` towards the top left of VS Code.
-   To run `.py` files, click the Run icon towards the top right of VS Code.

## Research Description
We're predicting complex stock prices using various models. This aligns with real-world contexts, which can lead to profits from stock investments, while also seeking insights from social contexts.
